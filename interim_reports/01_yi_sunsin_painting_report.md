# 충무공 이순신 영정 브라우저 페인팅 앱 구현 및 스트로크 최적화 보고서 (V5 최종)

## 1. 레퍼런스 사전 분석 노트 (Reference Study)
- **주제 및 구도**: `../reference.png` (`1280 × 1932`, 비율 `0.662526`) — 따뜻한 노란빛 한지·비단 족자 배경 중앙에 정면 대칭으로 앉아 있는 충무공 이순신 표준영정. 상단 중앙에 2단 흑갈색 사모와 양각, 상중단에 차분한 얼굴과 긴 수염, 하단 2/3에 넉넉한 홍단령과 가로로 맞잡은 소매, 가슴 중앙의 쌍호흉배·각대·백색 띠, 양 어깨 뒤의 표피(표범 가죽)가 배치됨. 부드러운 상단 정면광이 이마·콧등·사모 상단·상단 비단 배경에 온화한 광택을 주고, 하단 소매 주름과 양옆으로 갈수록 은은하게 깊어짐.
- **인물 식별 핵심 특징 7가지**:
  1. **깊고 차분한 눈매와 눈썹**: 바깥으로 날렵하게 빠지는 흑색 윗눈꺼풀선, 얇은 쌍꺼풀 주름, 따뜻한 캐치라이트가 맺힌 짙은 갈색 눈동자, 부드럽게 아치를 그리는 눈썹.
  2. **단정한 코·입술과 처진 콧수염**: 밝은 콧등, 절제된 콧망울 음영, 차분한 적갈색 입술선, 입꼬리를 감싸 내리는 풍성한 콧수염과 아랫입술 밑 작은 수염 뭉치.
  3. **세필(細筆) 수염과 구레나룻**: 목 피부와 홍단령 깃 위로 내려오는 수백 가닥의 1px급 수직 흑갈색 수염과 사이사이 비치는 피부·홍색 여백.
  4. **2단 사모와 나뭇결 무늬 양각**: 무광 흑갈색 말총 질감의 2단 관모와 이마 테두리, 검은 외곽선 안에 소용돌이 나뭇결이 비치는 반투명 양각.
  5. **쌍호흉배(雙虎胸背)**: 짙은 올리브·먹녹색 자수 바탕 위에 마주 앉은 두 마리 흰 호랑이/표범(작은 고리형 반점·얼굴·수염·말린 꼬리), 중앙 붉은 연꽃, 굽이치는 흰 파도문, 중앙 바위산과 다색 물결띠.
  6. **각대(角帶)와 상아색 띠**: 검은 직조 허리띠 위의 연금색 테두리 흑칠 장식판(중앙 사각판·양옆 세로 막대·외곽 원판)과 소매 아래로 내려오는 상아색 띠.
  7. **홍단령 의습선(衣褶線)·운보문·표피**: 옷깃·고름 매듭·소매 주름을 잇는 매끄러운 흑자색 윤곽선, 은은한 동색 운보문, 어깨 뒤로 방사형으로 퍼지는 깃털 표피와 초승달 반점.
- **색채 및 명도 특성**: 전체적으로 따뜻한 광물 안료·고비단 색온도(차가운 순백/네온톤 배제). 상단 고비단 `#EBD09B`→중하단 `#C48F5C`, 피부 `#DBA973`, 홍단령 `#802634`(하이라이트 `#A03744`, 음영 `#370E18`), 따뜻한 흑갈색 암부 `#24140D`~`#5D2F18`(죽은 순흑 방지), 흉배 올리브 `#3C442D`, 상아색 하이라이트 `#E6DEC6`(날림 방지).

## 2. 업그레이드 UI 및 렌더링 아키텍처 (V5)
- **상단 바**: `Paint` 제목, 실시간 브러시 타입(`Soft round` / `Bristle`) 및 28×28 캔버스 브러시 미리보기, `SIZE`(px), `OPACITY`(%), 대형 색상 스와치 + HEX + `R · G · B`, 재생 제어(`Pause/Play`, `Finish`, `Restart`), 우측 끝 `STAGE n OF 9` + 현재 단계명 실시간 동기화.
- **좌측 슬림 툴 레일**: 5종 인라인 SVG 아이콘(`Brush` 활성, `Pencil`, `Eraser`, `Fill`, `Zoom`).
- **이중 실시간 브러시 커서 (별도 오버레이)**: `#overlayCanvas`에서 실제 브러시 직경의 얇은 원형 커서가 2차 베지어 곡선 `B(t)`를 따라 연속 이동(드 카스텔조 분할로 획이 그려지는 과정을 실시간 표시)하며, `#referenceImage` 위 `#refCursor`가 동일 상대 좌표에서 동시 추적. 완료 시 두 커서 모두 숨겨 작품에 잔존하지 않음.
- **우측 사이드바 (위→아래)**: `REFERENCE` 썸네일 → 2개 통계 카드(`STROKES`, `COLORS MIXED`) → 9단계 `STAGES` 목록(완료 녹색 체크·현재 파란 점+하이라이트 행·예정 회색 빈 원, 각 단계 브러시 크기 표시) → 누적 `PALETTE` 그리드(RGB 32단계 양자화로 **121색** 병합, 최초 등장 순 누적 유지, 현재 색상 어두운 테두리 강조, 내부 세로 스크롤, 페이지 가로 스크롤 없음).
- **시간 기반 재생 페이싱**: 9단계 총 약 **44초**(30~60초 요구 범위) — 큰 붓 단계는 천천히, 세필 단계는 경쾌하게 진행하며, 국소 화가 손 모멘텀 샘플링으로 커서 이동이 자연스러움.

## 4. 실제 브라우저 검증 결과
- Chromium `1440×900` 기준: 콘솔 에러 **0건**, 전 에셋 HTTP 200, 가로 스크롤바 없음(`1440×900.27`), 팔레트 내부 세로 스크롤 정상.
- 진행 중(Stage 3 `Big shapes`, 1,056획) 캔버스 커서와 레퍼런스 링 커서 동시 추적, 단계 하이라이트 일치, 팔레트 실시간 증가(`65 colors`) 확인.
- 완료 시(Stage 9 `Final touches`, 84,933획, 121색) 두 커서 모두 숨김, 9단계 전체 녹색 체크, 캔버스 비율 `539.47 × 814.27 px` (`0.662518`) vs 원본 `0.662526` 정밀 일치.
